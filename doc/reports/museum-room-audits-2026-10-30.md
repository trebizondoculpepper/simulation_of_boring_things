# Museum room audits after layout C (2026-10-30)

The owner asked for one agent per hall to check, after layout C moved every doorway to an archway near its wall's end: that each hall's entrance and exit are clear, that nothing hangs in thin air, that the floor arrows line up with the way in and the way on and point the right way, and for any quick fix to get the machine layout working. The agents read the code and looked from inside each hall in the game; they changed nothing. Their findings, hall by hall (Halls 0, 5, 6 and 8 to follow: their audits were still running when this was first committed; several agents got no screenshots while ten ran at once, and their findings come from the code). The plan they feed is `doc/prompts/112-museum-rooms-layout-c.md`; the odd-numbered halls are this session's, the even-numbered another agent's.

## Across the halls: columns as exclusion zones

The owner, 2026-10-30, on the column bug Hall 1's audit found (its layout, and Halls 3, 9 and probably 6, subtract the hall's origin from `hallColumns()` twice, so the voxel router never sees the real columns and pipes and machines run into them): "we might need to make an improvement to the voxel-based pipe router so that we can mark the columns as exclusion zones for each room before we start plumbing it ... at least 10 centimeters outside of their bounding cylinder should be reserved." So: one shared function that gives every hall's columns as router regions forbidding runs (each column's whole height, its widest part, the capital or the base, plus at least 0.1 m all round), used by every hall's plumber instead of each building its own, and a test that no routed pipe or placed machine comes within 0.1 m of a column.
