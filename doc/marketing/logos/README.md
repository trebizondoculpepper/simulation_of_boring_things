# The Pool logo variants

Twenty transparent PNGs, the ten concepts the owner was shown on 2026-10-29. The owner chose 05, the circle (the title screen's logo, `resources/images/title/`, made from `05-circle-notext.png` by `scripts/title-logo.ts`); the other nine, rejected, are kept in `old/`. Each concept has an identical-position graphic-only and titled version. The title is exact, set in Avenir Next, and remains a separately composited layer in the image-making process. The image generation tool supplied the ten base marks; lettering was composited deterministically.
