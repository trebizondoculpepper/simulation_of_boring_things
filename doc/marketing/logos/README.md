# The Pool logo variants

Twenty transparent PNGs: each concept has an identical-position graphic-only and titled version. The title is exact, set in Avenir Next, and remains a separately composited layer in the image-making process. The image generation tool supplied the ten base marks; lettering was composited deterministically.
