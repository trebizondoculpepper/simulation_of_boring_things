# The museum's words

Each `hall-N-….md` file holds only the text a visitor reads in that hall, for the owner to edit. The game still takes its words from the code, so changes made in these files are carried into the code by hand.

`museum.md` is the developer reference: the same text with its sources in the code, line numbers and notes. Narration audio scripts live separately, in `../museum-narration.md`.
