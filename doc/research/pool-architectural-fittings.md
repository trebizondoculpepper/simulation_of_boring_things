# Pool architectural fittings: first reference pass

Research checked on 2026-10-20. The walkthrough uses original Three.js geometry. No manufacturer BIM model, texture or drawing has been imported. Publicly downloadable BIM content is useful for dimensions and arrangement, but its download terms do not automatically grant redistribution in this game.

| Fitting                 | Published reference                                                                                                                                                                                                                                                               | First scene treatment                                                                                                              | Later work                                                                                       |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Pool edge and overflow  | [AGROB BUCHTAL Wiesbaden edge system](https://www.bimobject.com/en-us/agrob_buchtal/product/Wiesbaden); [AstralPool transverse overflow grating](https://www.astralpool.com/en/en/pool-surround-equipment/grilles-for-overflow/transversal-grating.html)                          | Original pale coping strip and narrow contrasting overflow strip around the three basins.                                          | Choose an actual edge section and model gutter depth, handhold, grate joints and drainage route. |
| Wall ladder             | [AstralPool wall ladder](https://www.bimobject.com/en-us/astralpool/product/wall-ladder-standard-model-pool)                                                                                                                                                                      | Original simple twin rail and rungs on main and learner pools. The reference lists Ø43 mm rails; the prototype uses that diameter. | Check anchors, clearances, position and corrosion grade before final geometry.                   |
| Ceiling lighting        | [TRILUX Duroxo G2 LED](https://www.trilux.com/en/products/duroxo-g2-led/) is a pool-suitable luminaire resistant to water and chlorine atmospheres.                                                                                                                               | Repeated plain linear ceiling fittings with bright diffusers. They are visual stand-ins, not a photometric or electrical design.   | Select variants, spacing and illumination levels for the actual room geometry.                   |
| Basin drains and inlets | [AstralPool stainless drain grating](https://www.astralpool.com/en/en/pool-shell-equipment/main-drains/main-drain/drain-grating-in-stainless-steel.html) and [AstralPool BIM category](https://www.bimobject.com/en-us/categories/sports-recreation/swimming-pool) list examples. | Omitted until the pool hydraulics are specified.                                                                                   | Place multiple drains and return inlets according to a researched circulation design.            |

The [BIMobject user terms](https://business.bimobject.com/terms-of-service-eula) describe limited purposes for downloaded BIM content. We should not bundle those files as game assets without a license that explicitly permits it. The shapes above are original simplified meshes informed by published product descriptions.
